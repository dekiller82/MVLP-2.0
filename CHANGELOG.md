# Changelog

Newest first. The app shows the entries for the versions you skipped the first time it starts after an update. Format: `## version (date)`, then `### Section` headings with `-` bullets.

## 2.1.0 (2026-09-30)

### New
- Idle weekend schedule: one page per day of the coming race weekend with each session's start time in your local time.
- Copy diagnostics (Settings, About) copies versions, settings, panel state and the recent activity log for bug reports.
- The panel's own clock is set from your computer whenever it connects and every 6 hours.
- Start in tray option (Settings) for when MVLP starts at login. Launch at login now also works on Linux.
- What's new window after an update, and a What's new button in Settings, About.
- A new app icon: an LED panel with a lit M.
- Experimental: scrolling text in the panel's own text mode (two Studio test buttons).

### Improved
- The next race and last podium idle screens use a larger, easier to read 5x7 font.
- The tray menu ticks now show whether Multiviewer and Spotify are on, and the menu items work.
- The sidebar logo and the window icon match the new icon.

### Fixed
- The night hours time inputs were unreadable on the dark theme.
